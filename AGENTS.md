# Mathrix site instructions for AI maintainers

This repository is Mathrix's static GitHub Pages site. Before adding or updating project content, read [`skills/mathrix-blog-maintenance/SKILL.md`](skills/mathrix-blog-maintenance/SKILL.md). Follow its workflow for repository discovery, factual wording, data updates, and verification.

The public site is plain HTML, CSS, and JavaScript. Keep `CNAME` as `mathrix.eu.org`. Do not add a build dependency for routine content updates. Do not publish or push unless the user asks.

Before changing UI appearance, animation, language, or theme behavior, read [`docs/界面设计规范.md`](docs/界面设计规范.md). [`docs/站点维护说明.md`](docs/站点维护说明.md) describes the current pages, module responsibilities, and maintenance entry points. Keep design rules in the design specification and implementation details in the maintenance guide.
