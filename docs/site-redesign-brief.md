# Mathrix 站点改版需求清单

> 状态：第二十五轮恢复首页滚动叙事，待视觉评审。此文档记录本站的具体决策，不作为其他页面的通用规则。

## 已确定的方向

- 首页和导航去掉 M 徽标以及首屏的大号 M 图形，用 `Mathrix` 文本作为品牌识别。首屏的空间效果服务于项目与文字，不围绕字母 Logo 展开。
- 首页随机漫游展示 **6 项**，每个项目仍有相同入选机会；“换一组”保留。二级项目页继续收录全部项目。
- “查看全部项目”作为明确的下一步入口，给予更大点击面积、更高对比和更清楚的去向说明。无需用虚构排名或指标诱导点击。
- 卡片、顶栏、底栏和主要控件同属前景玻璃层，由统一的全局指针光场照亮；背景图形、雨和烟雾不接收指针反光。
- 中英文界面和浅色/深色主题均可手动切换，首次访问默认英文并根据系统主题自动选择；手动选择持久化。全站正文使用 Inter 为拉丁优先字体、Noto Sans SC 为固定中文网页字体；标题使用 IBM Plex Sans 为拉丁优先字体、Noto Serif SC 为固定中文网页字体。字体按标题/正文角色而非页面语言管理，首页标题每一行左对齐。
- 首页保留正常内容流，并在桌面端加入一个短的滚动叙事：同一个双行首屏标题随真实滚动进度下沉并合为一行，在 28%–62% 的入口滚动范围内连续对齐到“Discover at random / Start somewhere new.”上方；合并标题底边与探索标签保持 16px 间距，落点后仍由该标题元素持续追随探索标题的位置，视觉上随内容一起继续向上滚动。右侧抽象线框同步轻微放大、下移并向页面中部横移。项目区与首屏共用连续背景，不使用上推的抽屉或独立玻璃面板。动画不接管滚轮、触控板、滚动条或方向键，也不使用缓动或自动播放。项目区仍可自然抵达；窄屏和减少动态效果环境退化为静态流。
- 全页退回两张同色的预绘制柔和雾纹理，只用形状和漂移方向区分层次；不在浏览器逐帧模糊。雨滴和流星由 Canvas 生成不同起点、速度、长度与间隔，并按浏览器动画帧刷新、最高以 1.5 的像素比绘制；整体雨量与流星的渲染强度在上一版基础上再提高四倍，控件首次默认值均为 50%。浅色主题使用深蓝雨线与紫红流星，玻璃指针反馈使用 soft-light 的白色主光与蓝色散射；深色主题使用浅青雨线与金色流星，玻璃指针反馈使用 screen 冷色发光，确保两套颜色逻辑各自可见。右下角“氛围”面板可分别调整雨量与流星频率并保存选择。减动效环境停止自动运动，窄屏降低场景强度。
- 全页退回两张同色的预绘制柔和雾纹理，只用形状和漂移方向区分层次；不在浏览器逐帧模糊。雨滴和流星由 Canvas 生成不同起点、速度、长度与间隔，并按浏览器动画帧刷新、最高以 1.5 的像素比绘制；整体雨量与流星的渲染强度在上一版基础上再提高四倍，控件首次默认值均为 50%。浅色主题使用深蓝雨线与紫红流星，玻璃指针反馈使用 soft-light 的白色主光与蓝色散射；深色主题使用浅青雨线与金色流星，玻璃指针反馈使用 screen 冷色发光，确保两套颜色逻辑各自可见。右下角“氛围”面板为雾、雨、流星、指针光场和滚动叙事分别提供开关，设置会保存；所有效果首次默认开启，雨量与流星频率默认 50%。关闭滚动叙事时首页回到普通文档流，不保留 sticky 舞台或区块重叠。减动效环境停止自动运动，窄屏降低场景强度。
- 首页保留右侧抽象线框作为低注意力环境标记；它可在入口滚动叙事中轻微缩放和下移，深色主题继续使用近黑蓝灰底与少量冷蓝高光。
- 首页不拦截滚轮、触控板、滚动条或方向键；脚本只读取滚动位置并同步 CSS 变量，页面仍以普通文档流进入项目内容。
- 全部项目页的档案首屏采用完整的前景玻璃反光，并在首屏内提供按名称、分类和简介过滤的搜索入口。
- 顶栏偏好项常驻显示 `Language` 与 `Theme` 标签，选中值不再用凸起外框强调。顶栏、底栏、卡片和主要控件使用统一的磨砂材质。 顶栏与底栏以明确的 viewport 边界固定，`main` 而非 `body` 为两者预留空间，首页滚动转场不再移动页面框架。项目入口的停靠点额外避开顶栏实际高度与 18px 阅读间距。

## 已实现的步骤

1. 整理设计 token、双主题和中英文文案/项目简介的数据结构；保证页面在无动画时完整可读。
2. 移除徽标，重构首屏空间构图与滚动层次。
3. 增加随机展示数量，增强项目表面的操作反馈与全部项目入口。
4. 补充常驻环境动画、性能回退和减少动态效果模式。
5. 在中英、明暗、桌面/窄屏、键盘/鼠标下验收；检查自然滚动、链接、搜索和切换状态不丢失。

## 本轮修复与视觉评审

- 离开卡片时保留高光最后坐标，待透明度自然淡出，避免中心闪烁。
- 浏览器检查需比较同一滚动路径的首屏、中段、项目区入口及卡片区；验证标题与简介、项目区标题互不重叠，场景越过区块边界后仍可见。
- 46 个英文项目简介已补齐；后续可由项目作者逐条润色术语与语气。
