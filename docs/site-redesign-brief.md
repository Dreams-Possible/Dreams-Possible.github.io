# Mathrix 站点改版需求清单

> 状态：第十轮双状态滚动节奏修正，待视觉评审。此文档记录本站的具体决策，不作为其他页面的通用规则。

## 已确定的方向

- 首页和导航去掉 M 徽标以及首屏的大号 M 图形，用 `Mathrix` 文本作为品牌识别。首屏的空间效果服务于项目与文字，不围绕字母 Logo 展开。
- 首页随机漫游展示 **6 项**，每个项目仍有相同入选机会；“换一组”保留。二级项目页继续收录全部项目。
- “查看全部项目”作为明确的下一步入口，给予更大点击面积、更高对比和更清楚的去向说明。无需用虚构排名或指标诱导点击。
- 卡片、顶栏、底栏和主要控件同属前景玻璃层，由统一的全局指针光场照亮；背景图形、雨和烟雾不接收指针反光。
- 中英文界面和浅色/深色主题均可手动切换，首次访问根据浏览器语言与系统主题自动选择；手动选择持久化。
- 首页和项目区共用一套固定的几何远景，不以整块项目面板分隔。两行标题保持原字号，随滚动进入项目区上方的自然排版，最后固定在“随机漫游”标题之前，并随页面继续滚动；说明文字和按钮较早淡出。
- 全页退回两张同色的预绘制柔和雾纹理，只用形状和漂移方向区分层次；不在浏览器逐帧模糊。雨滴和流星由 Canvas 生成不同起点、速度、长度与间隔，以约 30 帧每秒和最高 1.5 的像素比绘制。右下角“氛围”面板可分别调整雨量与流星频率并保存选择。减动效环境停止自动运动，窄屏降低场景强度。
- 首页右侧结构由 CSS 线框组成；首屏将图形放在右半区中部偏下并放大，仅限制下滑后的放大倍率。深色主题改用近黑蓝灰底与少量冷蓝高光。
- 首屏与项目入口形成两个稳定画面。滚轮累计到明确意图后才进入或返回，切换采用约 1.45 秒的缓动；拖动/触控板停在过渡区后平缓吸附，上下方向键直接触发同样的过渡。到达项目入口后，项目列表正常滚动。
- 全部项目页的档案首屏采用完整的前景玻璃反光，并在首屏内提供按名称、分类和简介过滤的搜索入口。
- 顶栏偏好项常驻显示 `Language` 与 `Theme` 标签，选中值不再用凸起外框强调。顶栏、底栏、卡片和主要控件使用统一的磨砂材质。

## 已实现的步骤

1. 整理设计 token、双主题和中英文文案/项目简介的数据结构；保证页面在无动画时完整可读。
2. 移除徽标，重构首屏空间构图与滚动层次。
3. 增加随机展示数量，增强项目表面的操作反馈与全部项目入口。
4. 补充常驻环境动画、性能回退和减少动态效果模式。
5. 在中英、明暗、桌面/窄屏、键盘/鼠标下验收；检查自然滚动、链接、搜索和切换状态不丢失。

## 本轮修复与视觉评审

- 离开卡片时保留高光最后坐标，待透明度自然淡出，避免中心闪烁。
- 浏览器检查需比较同一滚动路径的首屏、中段、项目区入口及卡片区；验证标题与简介、项目区标题互不重叠，场景越过区块边界后仍可见。
- 46 个英文项目简介已补齐；后续可由项目作者逐条润色术语与语气。
