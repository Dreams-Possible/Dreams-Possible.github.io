# Mathrix 站点改版需求清单

> 状态：首页标题已改为落点处的静态副本接管滚动，待浏览器视觉评审。此文档记录本站的具体决策，不作为其他页面的通用规则。

## 已确定的方向

- 首页和导航去掉 M 徽标以及首屏的大号 M 图形，用 `Mathrix` 文本作为品牌识别。首屏的空间效果服务于项目与文字，不围绕字母 Logo 展开。
- 首页随机漫游展示 **6 项**，每个项目仍有相同入选机会；“换一组”保留。二级项目页继续收录全部项目。
- “查看全部项目”作为明确的下一步入口，给予更大点击面积、更高对比和更清楚的去向说明。无需用虚构排名或指标诱导点击。
- 卡片、顶栏、底栏和主要控件同属前景玻璃层，由统一的全局指针光场照亮；背景图形、雨和烟雾不接收指针反光。
- 中英文界面和浅色/深色主题均可手动切换，首次访问默认英文并根据系统主题自动选择；手动选择持久化。全站正文使用 Inter 为拉丁优先字体、Noto Sans SC 为固定中文网页字体；标题使用 IBM Plex Sans 为拉丁优先字体、Noto Serif SC 为固定中文网页字体。字体按标题/正文角色而非页面语言管理，首页标题每一行左对齐。
- 首页在桌面端使用一个加长的首屏区块和 sticky 舞台；项目区通过负上边距进入同一连续背景。双行首屏标题在入口滚动进度 28%–62% 之间下沉并合为一行，合并后的两段文字保持紧凑词距，目标落点在探索区标签上方。首屏的标签、简介和行动入口随滚动向上移动并逐渐淡出。项目区预先放置相同文案和样式的静态标题；到达落点时两组标题互换可见性，之后由项目区标题随正常文档流滚动，反向经过落点时切回首屏标题。脚本仅在初始化、字体加载完成和尺寸或偏好变化时测量标题与落点，滚动期间只更新位置与可见性。右侧抽象线框轻微放大、下移并向页面中部横移。动画不接管滚轮、触控板、滚动条或方向键，也不使用独立的缓动或自动播放。窄屏和减少动态效果环境退化为静态流。
- 全页使用两张预绘制的柔和雾纹理，运行时只移动图层。雨滴和流星由 Canvas 绘制，像素比最高为 1.5；雨量与流星频率默认值均为 50%。浅色主题使用深蓝雨线、紫红流星与普通混合模式的浅色指针高光；深色主题使用浅青雨线、暖色流星与 screen 混合模式的指针高光。首页和全部项目页共用同一套右下角“氛围”设置，包括雾、雨、流星、指针光场、线框呼吸和滚动叙事开关及恢复默认；设置跨页面保存，首次均默认开启。线框呼吸和滚动叙事只在首页可见其效果；关闭滚动叙事时首页回到普通文档流。减少动态效果时停止自动运动。
- 首页保留右侧抽象线框作为低注意力环境标记；整个线框在入口滚动叙事中轻微缩放和下移，外环、近景框与点在静止页面中保持较明显、缓慢的自主呼吸动画。用户可单独关闭线框呼吸；页面不可见或用户偏好减少动态效果时也会停止这些循环动画。深色主题继续使用近黑蓝灰底与少量冷蓝高光。
- 首页不拦截滚轮、触控板、滚动条或方向键；脚本只读取滚动位置并同步 CSS 变量，页面仍以普通文档流进入项目内容。
- 全部项目页的档案首屏采用完整的前景玻璃反光，并在首屏内提供按名称、分类和简介过滤的搜索入口。
- 顶栏偏好项常驻显示 `Language` 与 `Theme` 标签，选中值不再用凸起外框强调。顶栏、底栏、卡片和主要控件使用统一的磨砂材质。顶栏与底栏固定在视口边界，`main` 为两者预留空间。标题落点当前按探索区标签的位置和 16px 间距计算；修改布局时需再次检查顶栏遮挡与阅读间距。

## 已实现的步骤

1. 整理设计 token、双主题和中英文文案/项目简介的数据结构；保证页面在无动画时完整可读。
2. 移除徽标，重构首屏空间构图与滚动层次。
3. 增加随机展示数量，增强项目表面的操作反馈与全部项目入口。
4. 补充常驻环境动画、性能回退和减少动态效果模式。
5. 在中英、明暗、桌面/窄屏、键盘/鼠标下验收；检查自然滚动、链接、搜索和切换状态不丢失。

## 本轮修复与视觉评审

- 离开卡片时保留高光最后坐标，待透明度自然淡出，避免中心闪烁。
- 浏览器检查需比较同一滚动路径的首屏、中段、项目区入口及卡片区；验证标题与简介、项目区标题互不重叠，场景越过区块边界后仍可见。
- 浏览器视觉评审仍需检查中英文、明暗主题、快速往返滚动时两组标题的交接是否无跳位，以及项目区静态标题是否与探索区一起移动。
- 46 个英文项目简介已补齐；后续可由项目作者逐条润色术语与语气。
