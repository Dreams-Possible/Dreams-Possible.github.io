# 界面设计规范

本规范约束本站的视觉与交互。页面结构和维护入口见[站点维护说明](站点维护说明.md)。

## 视觉层级

品牌使用 `Mathrix` 文本字标。空间感通过抽象线框、透视、漫射光和留白表达，阅读区域保持稳定、清晰。

| 层级 | 职责 |
| --- | --- |
| 基底 | 低对比色场与纹理，建立空间方向 |
| 环境 | 雾、线框、雨和流星，提供背景深度 |
| 内容 | 文字、导航和项目卡片，承载阅读与操作 |
| 反馈 | 焦点、悬停、按下和选中状态 |

一个视口设一个主要视觉焦点。背景亮度低于文字和控件，装饰层设置 `aria-hidden`，并允许指针事件穿透。

## 色彩与材质

- 主题颜色使用语义变量，定义集中在 `assets/css/tokens.css`。主要角色包括 `canvas`、`surface`、`text-primary`、`text-secondary`、`border-subtle`、`accent`、`shadow` 和 `glow`。
- 深色主题采用近黑蓝灰底与冷蓝高光，浅色主题采用冷浅底与深蓝文字。两套主题都需区分背景、表面、正文和操作反馈。
- 玻璃表面使用半透明底色、细边线和适度模糊，关闭滤镜后仍需保证可读性。光源与阴影方向保持一致。
- 正文对比度目标至少为 4.5∶1，大号文字和必要的操作边界至少为 3∶1。
- 雨与流星分别配置明暗色板。浅色使用深蓝雨线、紫红流星，深色使用浅青雨线、暖色流星。

## 字体与布局

- 正文使用 Inter、Noto Sans SC，标题使用 IBM Plex Sans、Noto Serif SC。字体栈按正文和标题分工，拉丁字体在前、中文字体在后，系统字体用于加载失败时回退。
- 中英文保持相近的视觉重量。长仓库名和英文长词允许换行，避免挤压布局。
- 字号、间距、圆角和动效时长沿用现有尺度，同类组件保持一致。
- 标题左对齐。文字标签、数字和徽标应提供真实信息。
- 顶栏和底栏固定时，正文及锚点需预留空间。窄屏按自然阅读顺序布局，降低环境图层密度和位移。

## 动效与操作反馈

- 动效优先级为操作反馈、滚动叙事、环境运动。同一时刻只保留一个高注意力动作，导航和阅读区域保持稳定。
- 滚动动画直接读取真实滚动位置。滚轮、触控、键盘和浏览器后退继续按浏览器默认行为工作，内容入口始终可达。
- 玻璃表面共享全局指针光场，亮度随距离连续变化。高光离开时从最后位置淡出，背景装饰层独立绘制。
- 深色高光使用 `screen` 混合模式，浅色使用普通混合模式和白色漫射光。表面移动需避免边缘反复触发悬停。
- 所有可操作元素提供清楚的焦点、按下和选中状态。触屏保证点击面积，状态表达同时使用文字、边界或形状。
- 雾采用预绘制纹理，运行时仅移动图层。Canvas 限制像素比，连续动画优先使用 `transform` 和 `opacity`。
- 页面不可见时暂停连续动画。`prefers-reduced-motion: reduce` 下停止持续环境运动与滚动叙事，保留必要的状态反馈。

## 语言与偏好

- 首次访问默认英文，手动选择保存在本地。导航、按钮、日期、空状态和无障碍标签均需覆盖中英文，项目名称保留原名。
- 切换语言时保留当前页面、搜索条件、分类视图和随机项目结果。
- 主题提供浅色、深色和跟随系统三种模式，首次访问跟随系统。系统变化只影响跟随系统模式，手动选择优先。
- 主题切换保留页面、随机结果和滚动位置。主题初始化在首屏绘制前执行，减少亮暗闪烁。
- 偏好控件常驻显示用途标签，设置跨页面保存。存储不可用时允许在当前页面操作。

## 修改后的检查

涉及界面变更时，检查中英、明暗主题、桌面和窄屏组合，并覆盖以下行为。

- 鼠标和键盘均可操作，焦点可见，文字和按钮完整显示。
- 语言与主题切换后，搜索条件、分组视图和随机结果符合上述约定。
- 正常与减少动态效果模式下，内容和导航均可达。
- 首页正向和反向滚动时，标题交接连续，文字与顶栏互不遮挡。
- JavaScript 禁用时，`noscript` 的说明和 GitHub 入口可用。Canvas 或滤镜不可用时，正文与导航仍可使用。
