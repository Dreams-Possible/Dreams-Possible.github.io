# 站点维护说明

Mathrix 的静态 GitHub Pages 站点，使用 HTML、CSS 和原生 JavaScript 模块。域名由 `CNAME` 指定为 `mathrix.eu.org`，日常维护直接修改源文件。

## 页面与内容

| 页面 | 功能 |
| --- | --- |
| `index.html` | 随机展示六个不同项目，提供“换一组”和全部项目入口 |
| `projects.html` | 展示完整项目清单，支持按年份或分类分组，以及名称、简介和分类搜索 |

项目享有相同的首页入选机会，分类用于检索。语言或主题切换保留当前随机结果。项目数量从 `data/projects.js` 计算。

项目清单由 JavaScript 渲染。禁用 JavaScript 时，页面提供 GitHub 仓库列表入口。

界面翻译保存在 `data/i18n.js`。HTML 的 `data-i18n`、`data-i18n-aria` 和 `data-i18n-placeholder` 指定文案键，`assets/js/i18n.js` 在初始化和切换语言时更新文本、无障碍标签及输入提示。项目简介从 `data/projects.js` 选择对应语言，日期按当前语言格式化。

正文和控件在 HTML 中保留结构及文案键，文本、无障碍标签和输入提示统一由 JS 填充。修改这些文案时更新 `data/i18n.js`，项目数量及氛围强度读数由对应模块写入。

HTML 头部保留页面标题和描述，供初始文档及分享预览使用，修改时与翻译字典同步。`noscript` 保留脚本禁用时的静态说明和 GitHub 入口。

## 修改入口

| 文件或目录 | 职责 |
| --- | --- |
| `data/projects.js` | 项目名称、推送日期、分类和中英简介，按名称生成 GitHub 链接 |
| `data/i18n.js` | 公共界面中英文案 |
| `assets/js/main.js` | 公共功能初始化与页面选择 |
| `assets/js/theme-init.js` | 首屏绘制前读取主题、语言和动效开关，在 HTML 头部同步加载 |
| `assets/js/preferences.js` | 主题切换、系统主题跟随和偏好保存 |
| `assets/js/i18n.js` | 文案更新、语言切换和日期格式 |
| `assets/js/project-card.js` | 两个页面共用的项目卡片渲染 |
| `assets/js/pages/` | 首页随机展示与项目档案搜索、分组，各自管理页面状态 |
| `assets/js/effects/` | 氛围设置、天气 Canvas、指针光场和首页滚动叙事 |
| `assets/css/` | 主题变量、基础样式、公共组件、页面、布局和动效样式 |
| `styles.css` | 样式导入入口，导入顺序参与层叠计算 |
| `assets/fog-*.webp` | 两张预绘制雾纹理 |
| `scripts/check_projects.py` | 手动检查项目数据并联网核对 GitHub 仓库，只输出差异，文件由维护者更新 |
| `scripts/generate_fog.py` | 使用 Pillow 手动生成并覆盖两张 `assets/fog-*.webp` 雾纹理，网页直接加载图片 |

两个 HTML 页面各自包含导航、页脚和氛围控件。调整公共结构时同步检查两页。

`mathrix-localechange` 通知首页重新测量标题，`mathrix-motionchange` 通知动效模块更新设置。天气参数由氛围设置模块维护。

## 页面效果

具体视觉规则见[界面设计规范](界面设计规范.md)。当前页面采用以下实现。

- 顶栏和底栏固定，项目卡片与主要控件使用玻璃材质，共享指针光场。
- 正文和标题分别使用跨中英文字体栈，字体通过 Google Fonts 加载。
- 桌面首页使用 sticky 舞台。滚动时双行标题合并并移动，到达落点后由项目区的静态标题接管，反向滚动时切回。
- 标题几何在初始化、字体就绪、尺寸、语言或动效偏好变化时测量。滚动阶段更新位置与可见性，计算参数以 `assets/js/effects/scroll-journey.js` 和 `assets/css/home.css` 为准。
- 视口宽度不超过 760px、启用减少动态效果或关闭滚动叙事时，首页采用静态文档流。
- 全页雾纹理由 CSS 移动，雨和流星由 Canvas 绘制，画布像素比上限为 1.5。
- 右下角氛围面板提供雾、雨、流星、指针光场、线框呼吸和滚动叙事开关，以及雨量、流星频率和恢复默认操作。开关默认开启，两个强度默认 50%，设置跨页面保存。
- 线框呼吸和滚动叙事作用于首页，天气与光场供两页共用。页面隐藏或启用减少动态效果时暂停持续运动。

## 项目维护

按[项目维护技能](../skills/mathrix-blog-maintenance/SKILL.md)执行仓库核对、内容核实和预览。

- 根据项目 README 和代码编写一句具体的中英简介，保留原型、学习记录及设备适配范围。
- 日期使用 GitHub `pushed_at`，条目按日期倒序维护。
- 分类沿用嵌入式与控制、系统与设备、Web 与桌面、机器人与数据、工程工具。
- 本站仓库从项目清单中排除，收录与首页展示遵循相同的内容标准。
- 修改数据格式时同步调整检查脚本。脚本通过正则读取条目，依赖现有字段和格式。

## 本地检查

在仓库根目录核对项目数据。

```powershell
python scripts/check_projects.py
```

该命令使用 Python 标准库，检查本地数据后访问 GitHub API。输出 `ADD` 表示待收录仓库，`UPDATE DATE` 表示推送日期变化，`REVIEW` 表示需核对的仓库，`ERROR` 表示检查问题。脚本只输出结果，由维护者手动更新数据。目前远程查询限第一页、最多 100 个仓库。请求失败时会提示核对未完成，本地检查通过仍可能返回退出码 0，需查看终端输出。

调整雾纹理时，先安装 Pillow，再手动生成图片。

```powershell
python -m pip install Pillow
python scripts/generate_fog.py
```

此操作在本地生成并覆盖 `assets/fog-cyan.webp` 和 `assets/fog-secondary.webp`。普通预览和项目维护使用已有图片即可。

在仓库根目录打开终端，启动本地 HTTP 服务。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

保持终端运行，在浏览器访问 [首页](http://127.0.0.1:8000/) 和 [全部项目](http://127.0.0.1:8000/projects.html)。检查换一组、搜索、分组、偏好保存及[界面检查项](界面设计规范.md#修改后的检查)。按 `Ctrl+C` 停止服务。

原生 JavaScript 模块需要通过 HTTP 加载，双击 HTML 的 `file://` 打开方式会受到浏览器安全限制。若启动时报端口占用，先停止已有服务或换用其他端口，再访问对应地址。
